# 参考人物工程研究：大天使人物包

> 本文只记录用户声明已购买资源中的非表达性工程事实。Skill 中不包含原始几何、贴图、动画、音效或完整配置。

## 包结构

参考包同时包含：

- 萌芽/GermCache 与 germmod 风格目录
- DragonCore 客户端人物、物品和音效目录
- DragonCore 服务端 EntityModel 与 ItemModel 映射
- MythicMobs 的 Mob、Item 和 Skill 配置

## 人物结构统计

- Bedrock Geometry 格式：`1.12.0`
- Bedrock Animation 格式：`1.8.0`
- 人物图集：512×512
- 骨骼：19
- cube：116
- 带旋转 cube：48
- 零厚度平面：15
- 动画：18
- 最大骨骼层级深度：5
- 独立 item/effect 模型：4
- 独立音效：16

## 可复用方法

- 躯干分成多级，可以让胸、头、手臂和翅膀获得更自然的叠加旋转。
- 手腕下挂独立武器骨骼，使双武器能分别显示、隐藏、旋转和投掷。
- 同时保留独立 Java item model，供掉落物、盔甲架、投射物和技能特效使用。
- 命中盒作为不参与动画的独立根骨骼，转换工具必须保留。
- 动画 JSON 与 MythicMobs 技能配置共同构成完整动作：前者负责姿态，后者负责伤害、位移、音效与召唤物。
- 翅膀和剑气使用零厚度平面，需要专门测试透明排序和双面显示。

## 检查中发现的通用风险

- 通用 `geometry.unknown` 标识符在大型资产库中可能冲突。
- 基础贴图直接兼作 glowTexture 可能导致全身发光。
- 配置路径中的多余引号会变成路径字符，而不一定触发 YAML 解析错误。
- 技能块名称和音效文件名看似对应，也可能实际指向了另一个文件。
- 不同平台配置的 width/height 字段命名不一定等价，不能机械复制数值。
- idle、walk、death 等动画可能由加载器自动绑定；“未在技能文件引用”不等于无用。
