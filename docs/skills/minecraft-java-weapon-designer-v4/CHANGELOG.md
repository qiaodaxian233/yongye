# Changelog

## 4.0.0

- 新增人物、NPC、Boss 与技能特效设计能力。
- 新增 Bedrock Geometry 骨骼树、根骨骼、父级、循环依赖、cube、UV 与 visible bounds 检查。
- 新增 Bedrock Animation 时长、关键帧、骨骼引用和插值检查。
- 新增 DragonCore EntityModel、萌芽/Germ 风格配置与 MythicMobs 跨文件引用图。
- 新增动画—GCD—delay—伤害—音效—投射物同步检查。
- 新增发光遮罩、独立命中盒骨骼、透明平面和人物图集利用率规则。
- 新增人物包只读分析工具、人物项目模板和检查清单。
