# 冰霜大剑示例

## 项目假设

- Java 版本：待确认
- 实现方式：资源包 + 数据包
- 命名空间：`custom_weapons`
- 武器 ID：`frost_greatsword`
- 基础物品：钻石剑
- 贴图：32×32
- 模型：2D 手持模型

## 设计

冰霜大剑是一把以蓝白色冰晶为主题的重型武器。刀刃宽大，中央有一条浅青色能量脊，护手呈破碎冰晶形状，握柄使用深蓝色皮革。

建议定位：

- 单次伤害较高
- 攻击速度偏慢
- 击中时短暂减速目标
- 主动技能释放扇形冰霜冲击
- 技能需要冷却，避免连续控制

以上属性需要根据目标版本和实现方式落地。

## 贴图规格

- 画布：32×32
- 背景：透明
- 轮廓：1 像素深蓝灰
- 主刀刃：浅蓝灰
- 高光：接近白色的冰蓝
- 阴影：低饱和深蓝
- 护手：不对称冰晶
- 握柄：深蓝与灰黑交替
- 能量核心：青色 2×3 像素区域
- 光源方向：左上
